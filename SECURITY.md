# Security Policy

## Supported versions

Security updates are provided for the latest released major.minor line of ARTR Veyra.

## Reporting a vulnerability

Please report security vulnerabilities using **GitHub private vulnerability reporting** on this repository
(Security → Report a vulnerability).

Do not open public issues for security reports.

We will acknowledge receipt and provide an initial assessment as soon as practical.
Do not invent or expect a dedicated security email address unless one is published later by the project maintainers.
