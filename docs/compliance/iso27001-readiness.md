# ISO/IEC 27001 readiness notes

These notes help operators map ARTR Veyra controls to an ISO/IEC 27001 ISMS. **This project is not ISO/IEC 27001 certified** and makes no certification claim.

| Theme | Veyra support |
|-------|----------------|
| Access control | JWT/API key, authorization policies |
| Cryptography | TLS termination guidance, hashed API keys |
| Operations | Health probes, runbooks, systemd/Windows Service |
| Supplier/supply chain | NuGet audit, lock files, Dependabot, CodeQL |
| Logging | Correlation IDs, OpenTelemetry |

Organizations remain responsible for their ISMS, policies, and audits.
