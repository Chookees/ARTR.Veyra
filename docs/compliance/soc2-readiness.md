# SOC 2 readiness notes

These notes help operators prepare evidence for a SOC 2 examination. **This project is not SOC 2 certified** and makes no compliance claim.

| Trust service criteria theme | Veyra contributions |
|------------------------------|---------------------|
| Security | AuthN/AuthZ, rate limits, secure defaults |
| Availability | Health endpoints, graceful shutdown, service units |
| Confidentiality | Secret resolver, non-secret config summaries |
| Processing integrity | Config validation, transform allowlist |
| Privacy | Not a primary personal-data processor; operators must assess deployments |

A formal SOC 2 report requires an independent auditor and organizational controls beyond this repository.
