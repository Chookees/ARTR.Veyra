# Governance

ARTR Veyra is maintained by ARTR contributors through GitHub pull requests and issues.

## Decision making

- Routine changes: consensus via pull request review
- Architecture changes: documented in `docs/architecture/adr/`
- Security issues: handled privately per [SECURITY.md](SECURITY.md)

## Maintainers

Maintainers are listed in [CODEOWNERS](.github/CODEOWNERS) when published. Until then, repository administrators on GitHub act as maintainers.

## Releases

Releases are cut from tagged commits using the GitHub Actions release workflow (native artifacts only; no container images).
